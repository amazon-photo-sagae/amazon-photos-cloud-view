# 管理画面の操作体験版

このフォルダは本番と接続しない静的な試作品です。認証は未実装です。本物の情報・秘密情報を入力しないでください。
URLは保存・形式確認だけを行い、写真取得やYouTubeへの接続を行いません。音源を含みません。
登録情報は専用キー `sagae-admin-demo-matches-v1` でブラウザ内に保存します。端末間の共有はありません。
同日・同じ相手・同じ試合番号の重複は防止します。並び順は日付降順、同日は試合番号降順です。
正式ロゴの原本を使用しています。

## PCで確認

Pythonがある場合、このフォルダで `python -m http.server 4180 --bind 127.0.0.1` を実行し、ブラウザでポート4180のローカルサーバーを開きます。
HTTP/HTTPS上での利用を推奨します。HTML直接開きではブラウザ内保存などの挙動が環境によって異なります。
スマホでの確認にはPCの開発者ツールのデバイス表示、または別途許可したテスト専用HTTPS配信を利用します。今回、外部公開は行いません。

## 操作

1. 「新しい試合」で日付・大会名・対戦相手・試合番号を入力します。
2. サンプルPHOTO URLとして `https://www.amazon.co.jp/photos/share/SAMPLE-NEW` を貼り付けて登録します。
3. 同じ試合の「編集・MOVIEを追加」を開き、`https://youtu.be/SAMPLE-NEW` を追記して保存します。
4. カードが増えず、PHOTOが残った状態でMOVIE登録済みになることを確認します。
5. 再読み込みすると同じブラウザの内容が残ります。「サンプルに戻す」で初期化できます。

既存の統合アプリは親フォルダにそのまま残しています。
本番運用にはサーバー側の管理者認証・権限確認・安全な保存処理・バックアップなどが必須です。この試作品を本番登録画面として使用しないでください。
